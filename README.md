
# CST3144 After-School Classes - Frontend

Vue 3 + Vite frontend application for CST3144 coursework.

## Features
- **Vue 3 (Composition API)** with Vite.
- Centralized API configuration in `src/config/api.js`.
- Native `fetch` API service in `src/services/apiService.js` (No Axios).
- Relative base path configured in `vite.config.js` (`base: './'`) for seamless GitHub Pages deployment.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production (GitHub Pages)
npm run build
```
